==================================
QSCAT 0.5.0 Changelog - 2026-11-20
==================================


Fixed
=====

- Fixed QSCAT failing to load on macOS with `OSError: dlopen(...alglib316_64free.so...)` (`#89 <https://github.com/qscat/qscat/issues/89>`_, `#91 <https://github.com/qscat/qscat/issues/91>`_, `#112 <https://github.com/qscat/qscat/issues/112>`_).
- `Shoreline Change Tab`: Fixed `ValueError: could not convert string to float` when reading the confidence interval on systems using a comma decimal separator (`#82 <https://github.com/qscat/qscat/issues/82>`_).


Changed
=======

- Removed the bundled ALGLIB library. The Student's t-distribution used for LCI and WCI is now computed in pure Python, so QSCAT no longer depends on platform-specific binaries.
- Improved documentation: fixed typos, corrected formulas, and updated the Forecasting outputs and attribute tables.
