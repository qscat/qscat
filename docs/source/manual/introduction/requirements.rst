************
Requirements
************


To use QSCAT, you need QGIS, which is a free and open-source Geographic Information System (GIS) software. You can download different versions of QGIS from the `QGIS website <https://qgis.org/download/>`_ (see the versions below). Ensure that your system meets the requirements for QGIS: a standard PC with at least 4GB of RAM running on Windows, Linux, or macOS.

Since QSCAT is a plugin for QGIS (not standalone software), if you meet the system requirements of QGIS, QSCAT should run fine on your system.

QGIS versions
-------------

QSCAT is currently tested on **QGIS 3.44.15**, the long-term release (LTR) as of November 2026.

QSCAT requires QGIS 3.22 or later. Other versions will probably work, but we recommend QGIS 3.44 to avoid compatibility issues.
